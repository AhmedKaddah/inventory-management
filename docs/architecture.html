The frontend and backend are separate processes that talk only over HTTP. CORS is open to all origins, so the frontend can call the API directly.

Filter values of all are ignored. Inventory has no time dimension, so the month filter does not apply to it.

Data flow: changing a filter on the Dashboard

  1. User changes a filter The user picks a value in FilterBar.vue. The change updates the shared refs in useFilters.js.
  2. View reloads its data Dashboard.vue watches the filters and calls four API methods in parallel with Promise.all: dashboard summary, orders, inventory, and backlog.
  3. Client builds the request api.js turns the filters into a query string and drops any value set to all. For example, ?warehouse=Tokyo&month=2025-09.
  4. FastAPI filters in memory The handler runs apply_filters() for warehouse, category, and status. Then filter_by_month() matches the order_date prefix against the month or quarter.
  5. Response is validated and returned For list endpoints, Pydantic checks each record against its response model before sending the JSON.
  6. Views derive the UI The response goes into raw refs such as allOrders and inventoryItems. Computed properties build KPIs, tables, and charts from those refs. Some metrics are recalculated in the browser from the raw orders list, so they can differ from the server summary.

All data is read-only and loaded once at startup. Nothing is written back to disk, so restarting the server restores the original data.

Known gaps

Severity Finding
Broken api.js calls /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, but the backend has no routes for them. In App.vue, task calls fail, log to the console, and leave only the mock tasks from useAuth.js.
Dead code views/Backlog.vue is not registered in the router and is not imported anywhere. Backlog data appears only through BacklogDetailModal on the Dashboard.
Inconsistent Reports.vue calls Axios directly with hardcoded URLs instead of going through api.js.
Hardcoded The API base URL is fixed to http://localhost:8001/api, and quarter boundaries in the backend are hardcoded to 2025.
By design No authentication, a mock user profile, and CORS open to all origins. This is a demo, not production-ready.

Running locally

./scripts/start.sh      # starts both servers (macOS / Linux)
./scripts/stop.sh       # stops both servers

# or manually
cd server && uv run python main.py     # API on http://localhost:8001
cd client && npm run dev               # UI on http://localhost:3000
